# 🏅 The Story of Olympics | Tableau Dashboard

## 📌 Project Overview

The Story of Olympics is a data visualization project created using Tableau Public. It explores Olympic participation, athlete demographics, geographical locations, and medal achievements through interactive dashboards and visualizations.

## 🎯 Project Objectives

- Analyze Olympic participation across different years.
- Explore male and female athlete participation.
- Understand athlete age and height-weight distributions.
- Visualize Olympic cities on a world map.
- Compare Gold, Silver, and Bronze medals across countries.
- Identify top-performing athletes and sports.
- Explore Olympic data using interactive filters.

## 📊 Dashboards

### 1. Overall Olympic Analysis

- Map of Olympic cities
- Country-wise medal tally
- Gold, Silver, and Bronze medal analysis
- Year-based filtering

### 2. Exploratory Data Analysis (EDA)

- Year-wise participation
- Gender distribution pie chart
- Athlete age histogram
- Height-weight scatterplot

### 3. Country-wise Analysis

- Country medal tally by year
- Top athletes by medals
- Sports-wise medal distribution
- Country and medal filters

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open `Story-of-Olympics.twbx` in Tableau Desktop or a compatible Tableau application.
3. Navigate through the Overall, EDA, and Country-wise story points.
4. Use the available filters to explore the visualizations.
